# MiniMax H3 提示词指南

## 目标

H3 提示词要把“画面、声音、参考素材和时序”组织成同一份可执行说明。先确认模式，再写提示词。

模式矩阵见 [references/mode-matrix.md](references/mode-matrix.md)。

## 工作顺序

1. 确认用户使用的是 T2VA、I2VA、FL2VA、L2VA 还是 Ref2VA。
2. 列出输入素材，并给每个素材加明确标签，例如 `@image1`、`@video1`、`@audio1`。
3. 说明素材各自控制什么，不控制什么。
4. 写画面动作和镜头时间线。
5. 写整体声景、对白、音乐和关键声音事件。
6. 对齐首帧、尾帧或参考时间点。
7. 检查模型模式、参考数量、时长和画幅限制。

如果平台模式定义不清楚，要求用户贴出当前界面的模式说明；不要凭猜测扩展模型能力。

## 提示词结构

默认按以下段落：

```text
[模式与素材]
@image1 是角色身份参考；@image2 是场景与主光参考。

[整体声景]
环境、音乐、对白、音效、留白。

[画面与动作]
从哪个状态开始，主体在什么时间做什么，摄影机如何运动，结束在什么状态。

[时序与关键帧]
首帧、尾帧、音频同步点或参考视频中的关键动作点。

[一致性与排除]
身份、服装、空间、光线、画面比例和禁止漂移项。
```

## 参考素材规则

- 身份参考只控制身份，不要让模型连同参考图的背景和构图一起复制。
- 场景参考只控制空间、光线和氛围，不要覆盖角色身份。
- 视频参考先说明是在控制动作、节奏、镜头还是风格。
- 音频参考明确是音乐、对白、环境声还是节奏参考。
- 多个参考发生冲突时，明确优先级。

## 音频与对白

把声音分为：

- 对白：谁、说什么、什么时候说、画面内还是画外
- 环境声：地点、距离、天气、空间大小
- 动作音效：声源、接触材质、包络
- 音乐：风格、情绪、进出点和是否让位给对白

默认对白优先，音乐不盖住台词，音效不填满每个空隙。

## 质量门

- 每个参考素材都有明确角色，没有“顺便参考”的模糊说法。
- 动作、镜头和声音落在同一时间轴。
- 段落之间有真实的终点和起点。
- 没有把未验证的模型能力写进提示词。
- 禁止项只覆盖真实风险，不阻塞合理创作。

## 交付

输出最终提示词、参考素材映射表、声音计划、关键帧/时间点表和仍需用户提供或验证的字段。
